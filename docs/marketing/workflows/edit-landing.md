# Правка существующего лендинга

1. Зафиксировать base и заполнить [Delta Brief](../templates/delta-brief.md): точные страницы/секции, before/after intent и всё, что должно сохраниться.
2. Проверить Product Facts, evidence и статусы только для затронутых claims.
3. Получить точные approvals для всех затронутых gates: positioning, copy, design. Не затронутые approvals не переоткрывать.
4. Реализовать только перечисленную delta. Рефакторинг, попутная правка текста/дизайна и расширение scope запрещены.
5. Создать preview и сравнение с base; проверить сохранённые части.
6. Провести независимый review фиксированных base/head и brief identity.
7. Получить отдельное approval публикации; перепроверить механизм GitHub Pages; затем выполнить разрешённый merge/deploy и post-check.

Product Facts и handoff обновляют знания, но не создают Delta Brief и не запускают правку автоматически.
